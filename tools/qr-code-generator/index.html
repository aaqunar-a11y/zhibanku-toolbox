📱 离线二维码生成器

离线二维码生成器把网址、文本、WiFi 账号等任意内容直接画成一张二维码图片。在下方的输入框里粘贴或键入要转换的内容，选一下容错等级和颜色，点「生成二维码」按钮，图形会立刻出现在预览区；确认能扫之后，点「下载 PNG」按钮就能把高清图片保存到电脑，打印出来或发给别人都可以。整个过程完全在你的浏览器里完成，输入的内容不会上传到任何服务器，页面打开一次后断网也能继续使用。

内容本地生成 · 不上传 · 断网可用 · 支持中文

怎么用

  1. 把网址或任意文本粘贴进输入框（也可以点「填充示例」按钮先看看效果）。
  2. 按需调整容错等级、点块大小和颜色，不懂就保持默认。
  3. 点「生成二维码」按钮，图形立刻出现在下方预览区。
  4. 用手机相机先扫一下验证，确认后点「下载 PNG」保存高清图片。

注意事项

  • 二维码内容上限约两千多字节，粘贴超长文章会生成失败，这种情况建议先放短链接或网盘链接
  • 容错等级越高图案越密、容量越小，但破损、遮挡后仍可扫出，印刷张贴建议选 Q 或 H
  • 前景色与背景色对比度要够，浅灰配白色手机很难识别，深色块配浅色底最稳
  • 下载得到的是 PNG 位图，放大打印时把「点块大小」调大（比如 16 或 24）再导出，边缘更清晰
  • 中文和 emoji 都能编码，但占的字节数是英文的三到四倍，同样的容量会明显变小

常见问题

生成的二维码会过期吗？

不会。二维码就是把内容画成图形，生成后信息固化在图案里，永久可扫，与本网站或任何服务器都不再有关系。

输入的内容会被上传吗？

不会。整个生成过程在浏览器本地完成，不发送任何网络请求，断网状态下同样可以正常使用。

为什么我扫不出来？

常见原因有三个：打印太小或太糊（换高清大图重印）、颜色对比不够（改回深前景浅背景）、或内容超长导致点位太密。先把点块大小调到 8 以上、容错选 M 试试。

怎么做扫了直接连 WiFi 的二维码？

点「填充示例」按钮选择 WiFi 示例，把格式 WIFI:T:WPA;S:网络名;P:密码;; 里的网络名和密码改成你自己的，重新生成即可。安卓手机相机可以直接扫，苹果手机需要用扫码类应用识别。

可以批量做很多个吗？

本页是逐个生成的界面。如果你有大量数据要批量打成二维码，可以下载本工具的 Windows 绿色版离线使用，或到知办库工具箱看看批量版本。

适用场景

  • 把店铺网址、收款名片、活动报名页做成二维码贴在桌上或海报上
  • 生成 WiFi 二维码，客人来了扫一下就联网，不用口述密码
  • 把长文本、收货信息、设备序列号转成码贴在物品上做标记
  • 离线环境（内网、仓库、车间）里传递文本，扫一下就能读取
