HTML 实时预览工具

本工具是一个纯前端的 HTML 实时预览编辑器，让您无需安装任何软件即可在浏览器中编写和测试 HTML 代码。在左侧的代码编辑区粘贴或输入您的 HTML 代码（支持 CSS 和 JavaScript），点击「运行预览」按钮，右侧的预览区域会立即渲染出页面效果。您也可以使用「自动刷新」模式，在输入时实时更新预览。所有代码均在您的浏览器本地运行，不会上传到任何服务器，请放心使用。

快捷预设

注意事项

  • 本工具完全在浏览器本地运行，您的代码不会上传到任何服务器，可放心处理敏感内容。
  • 预览区域使用 iframe 沙箱渲染，默认允许脚本执行，但部分高级 API（如本地文件访问、跨域请求）可能受限。
  • 自动刷新模式会在您停止输入 1 秒后自动更新预览，频繁输入时可能造成短暂卡顿，建议大段代码时使用手动运行。
  • 代码中的外部资源（如图片、CDN 脚本）需要网络连接才能加载，纯离线环境下可能无法显示。
  • 预览区域不支持响应式设备模拟，如需测试移动端效果，请使用「新窗口打开」功能。
  • 若代码中存在语法错误，预览区域可能显示空白，请检查控制台报错信息。

怎么用

  1. 在左侧代码编辑区输入或粘贴您的 HTML 代码，支持完整的 HTML、CSS 和 JavaScript。
  2. 点击「运行预览」按钮手动渲染，或点击「自动刷新」开启输入即预览模式。
  3. 右侧预览区域会实时显示渲染结果，您可以直接与页面交互（点击按钮、填写表单等）。
  4. 如需在独立窗口查看效果，点击「新窗口打开」；需要复制代码时点击「复制代码」。
  5. 使用「重置」按钮恢复默认示例代码，「清空」按钮清空编辑区。

常见问题

为什么我的 JavaScript 代码没有生效

请检查代码中是否包含完整的 script 标签，且没有语法错误。预览区域支持脚本执行，但部分浏览器 API 可能受限。

自动刷新模式卡顿怎么办

自动刷新会在输入停止后触发，如果代码量较大建议关闭自动刷新，改用「运行预览」按钮手动控制渲染时机。

预览区域显示空白是什么原因

通常是代码存在语法错误或未闭合标签导致。请检查代码完整性，或点击「重置」恢复默认示例代码测试。

能否预览外部链接的页面

不能。本工具只渲染您输入的代码，不支持加载外部 URL。如需预览外部页面，请直接访问该网址。
