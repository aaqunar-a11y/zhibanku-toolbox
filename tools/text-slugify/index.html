标题转 URL Slug 生成器

本工具用于把中文或英文标题快速转换为适合 URL 使用的 Slug 格式（小写字母、数字、连字符）。您只需在下方输入框粘贴或输入标题文字，然后点击「生成 Slug」按钮，转换结果会立即显示在结果区域。支持自定义分隔符、是否保留数字、是否去除停用词等选项，并提供多种快捷预设按钮。整个过程完全在浏览器本地运行，不会上传任何数据。

注意事项

  • 本工具为纯本地运行，所有文字处理均在您的浏览器内完成，不会上传任何数据到服务器。
  • 中文标题会先转换为拼音再生成 Slug，多音字可能不准确，建议对重要链接手动核对。
  • 「去除停用词」选项会过滤常见英文虚词（如 the、a、an、of、for 等），对中文无效。
  • 分隔符仅支持 1-3 个字符，推荐使用连字符「-」或下划线「_」，其他符号可能影响 URL 兼容性。
  • 生成结果不会自动复制，需要手动点击「复制结果」按钮。
  • 若输入内容为空或全部为标点符号，点击「生成 Slug」会提示错误。

怎么用

  1. 在输入框中粘贴或输入需要转换的标题文字，例如「2025 年最新前端开发指南」。
  2. 根据需要调整选项：分隔符、是否保留数字、是否转小写、是否去除停用词。
  3. 也可以点击上方「快捷预设」按钮，一键切换常用配置。
  4. 点击「生成 Slug」按钮，转换结果会显示在下方结果区域。
  5. 点击「复制结果」按钮即可将生成的 Slug 复制到剪贴板。

常见问题

中文标题转换后变成拼音，准确吗？

本工具使用内置的拼音映射表进行转换，常见字词基本准确，但多音字和生僻字可能存在误差，建议生成后人工核对。

为什么我的标题生成后是空的？

如果输入内容只包含标点符号或特殊字符，过滤后可能没有有效字符。请检查输入是否包含中文或英文字母。

「去除停用词」有什么作用？

该选项会删除英文标题中的常见虚词（如 the、a、an、of、for、and 等），让 Slug 更简洁。对中文标题没有影响。

生成结果可以直接用于网址吗？

可以。生成的 Slug 只包含小写字母、数字和您指定的分隔符，符合 URL 规范，可直接用于链接路径。
