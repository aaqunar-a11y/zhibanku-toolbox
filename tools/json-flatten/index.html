JSON 拍平工具

本工具将嵌套的 JSON 对象拍平为「点路径」扁平结构，例如把 {"a":{"b":1}} 转换为 {"a.b":1}，方便数据展平、日志分析与表格导入。您只需在左侧输入框粘贴 JSON 内容，点击「拍平 JSON」按钮，结果即刻显示在右侧。若需要还原，将拍平后的 JSON 粘贴到左侧，点击「反向还原」即可恢复嵌套结构。整个过程完全在浏览器本地运行，数据不会上传到任何服务器。

快捷预设：
提示： 拍平后的键名使用点号分隔路径，如 a.b.c。数组索引使用数字表示，如 items.0.name。反向还原时，工具会自动识别数字键并还原为数组。

注意事项

  • 输入必须是合法的 JSON 格式，否则会提示错误。支持对象和数组作为根节点。
  • 拍平后的键名使用点号分隔路径，如果原始键名本身包含点号，可能造成还原歧义，建议避免。
  • 数组会被拍平为数字索引路径，如 arr.0、arr.1，反向还原时数字键会自动转回数组。
  • 所有处理均在浏览器本地完成，数据不会上传到任何服务器，可放心处理敏感数据。
  • 当 JSON 数据量较大（超过 1MB）时，处理速度可能变慢，建议分块处理。
  • 反向还原时，如果拍平后的键名不符合点路径规则（如键名中有非法字符），可能无法正确还原。

怎么用

  1. 在左侧输入框中粘贴您的 JSON 数据，或点击上方「快捷预设」按钮快速填入示例数据。
  2. 点击「拍平 JSON」按钮，将嵌套结构转换为点路径扁平格式，结果出现在右侧输出框。
  3. 如需还原嵌套结构，将拍平后的 JSON 粘贴到左侧，点击「反向还原」按钮。
  4. 点击「复制结果」按钮可将输出内容复制到剪贴板，点击「重置」清空所有输入输出。

常见问题

拍平和还原是精确可逆的吗

对于标准 JSON 数据，拍平后再还原可以恢复原始结构。但如果原始键名包含点号或数字键与数组索引冲突，可能出现歧义。

数组会被如何处理

数组元素使用数字索引作为路径段，例如 items.0.name。反向还原时，工具检测到数字键会自动重建数组。

数据会发送到服务器吗

不会。所有处理逻辑都在您的浏览器本地运行，没有任何网络请求，数据完全不会离开您的设备。

支持多深的嵌套层级

理论上支持任意深度的嵌套，但过深的层级（超过 100 层）可能导致浏览器卡顿，建议控制在 50 层以内。
