本工具用于解析中国大陆18位居民身份证号码，自动提取户籍地区、出生日期、性别和校验位信息。您只需在下方输入框中粘贴或输入完整的18位身份证号，点击「解析身份证」按钮，解析结果会立即显示在下方结果区域中。整个过程完全在浏览器本地运行，身份证数据不会上传到任何服务器，请放心使用。

注意事项

  • 本工具仅支持18位身份证号码，15位旧版号码请先升级为18位后再解析。
  • 身份证号码第17位为奇数表示男性，偶数表示女性；第18位为校验码，可能是数字0-9或字母X（大写）。
  • 解析结果中的地区信息基于身份证前6位行政区划代码，部分代码可能因行政区划调整而显示为「未知地区」。
  • 所有解析均在您的浏览器本地完成，身份证数据不会上传至任何服务器，请放心使用。
  • 本工具不存储任何输入记录，刷新页面后所有数据自动清除。
  • 请勿使用他人身份证号码进行测试，保护个人隐私。

怎么用

  1. 在输入框中粘贴或输入完整的18位身份证号码。
  2. 也可以点击上方「快捷示例」按钮，快速填入一个示例号码。
  3. 点击「解析身份证」按钮，系统将自动校验并解析。
  4. 解析结果会显示在下方结果区域，包含地区、生日、性别、校验位等信息。
  5. 如需保存结果，点击「复制结果」按钮即可复制到剪贴板。

常见问题

身份证号码校验失败是什么原因

可能是号码长度不足18位、包含非法字符、出生日期无效或校验码不匹配。请检查输入是否正确，注意最后一位X需大写。

为什么地区显示未知

身份证前6位是行政区划代码，部分地区代码已随行政区划调整而变更。本工具内置了常用代码库，未收录的代码会显示未知地区。

15位身份证能解析吗

不能。本工具仅支持18位身份证号码。15位旧版号码需先按规则升级为18位（补全出生年份、添加校验码）后再解析。

数据会上传到服务器吗

不会。所有解析逻辑都在浏览器本地运行，没有任何网络请求，您的数据完全不会离开您的设备。
