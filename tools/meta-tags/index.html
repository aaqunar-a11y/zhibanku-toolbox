SEO Meta 标签生成器

填入页面信息，一键生成基础 SEO、Open Graph 与 Twitter Card 标签，并校验长度。

各标签的作用

标签作用建议长度
title搜索结果标题、浏览器标签30–60 字符
description搜索结果摘要，影响点击率80–160 字符
canonical声明规范网址，避免重复内容完整绝对 URL
og:*微信、Facebook 等分享卡片标题/描述同上
twitter:cardTwitter/X 分享样式有图用 summary_large_image

长度只是经验值：搜索引擎会按像素宽度截断，中文字符通常比英文字母更「宽」，因此中文页面可适当取短一些。

常见问题

description 会影响排名吗？

它不直接作为排名因素，但会显著影响点击率——一段准确、有吸引力的描述能提升点击，间接有利于流量与排名。

canonical 必须填吗？

当同一内容存在多个可访问网址（带参、www 与非 www、分页）时建议填写，指向你希望被收录的那个版本。工具会原样输出你填写的地址。

生成的代码放哪里？

放在网页 <head> 中靠前的位置，确保 title、description、canonical 先于脚本加载，便于爬虫尽早读取。
