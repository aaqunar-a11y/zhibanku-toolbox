## 📖 简介

在线 SEO Meta 标签生成器：填写标题、描述与网址，一键生成 title、description、canonical 以及 Open Graph 与 Twitter Card 标签，并给出标题与描述的长度校验。

SEO Meta 标签生成器帮你快速写出网页头部要用的标题、描述与网址声明标签。在页面上方依次填写网页标题、描述文字和网址，哪项不需要就留空，然后点「生成代码」按钮，下方代码区会输出一段可直接粘进页面头部的 HTML。改了任意一项再点一次就能拿到最新版本，复制后放进模板保存即可生效。

## ❓ 常见问题

<details>
<summary>description 会影响排名吗？</summary>

它不直接作为排名因素，但会显著影响点击率——一段准确、有吸引力的描述能提升点击，间接有利于流量与排名。
</details>
<details>
<summary>canonical 必须填吗？</summary>

当同一内容存在多个可访问网址（带参、www 与非 www、分页）时建议填写，指向你希望被收录的那个版本。工具会原样输出你填写的地址。
</details>
<details>
<summary>生成的代码放哪里？</summary>

放在网页 <head> 中靠前的位置，确保 title、description、canonical 先于脚本加载，便于爬虫尽早读取。
</details>
