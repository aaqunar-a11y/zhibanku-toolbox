## 📖 简介

知办库免费在线 JSON 美化工具：用 2/4 空格或 Tab 缩进美化紧凑 JSON，并支持按 A–Z 排序键。纯前端运行，文本不上传。

JSON 美化工具用来把挤成一行的紧凑 JSON 展开成易读的多行格式。把 JSON 粘贴到上方输入框，选择缩进方式（2 空格、4 空格或 Tab），需要的话再勾选按 A–Z 排序键，然后点「开始美化」按钮，格式化后的 JSON 显示在下方结果框，可直接复制，出错时会提示具体行号方便你定位。
