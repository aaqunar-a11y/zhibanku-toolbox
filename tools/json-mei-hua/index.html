JSON 美化 — 让 JSON 更易阅读

JSON 美化工具用来把挤成一行的紧凑 JSON 展开成易读的多行格式。把 JSON 粘贴到上方输入框，选择缩进方式（2 空格、4 空格或 Tab），需要的话再勾选按 A–Z 排序键，然后点「开始美化」按钮，格式化后的 JSON 显示在下方结果框，可直接复制，出错时会提示具体行号方便你定位。

在下方粘贴紧凑或压缩后的 JSON，选择喜欢的缩进方式即可美化。全程本地完成、不上传。

注意事项

  • JSON 有语法错误时不会输出结果，会提示出错的大致行号，先改好再美化。
  • 美化只增删空白和换行，不会改动数值精度和字符串内容，键顺序默认也保持原样。
  • 勾选按 A–Z 排序会重排所有键，嵌套对象同样受影响，别用在需要保序的场景。
  • 几兆以上的大文件解析会卡顿几秒，建议分段处理或换个时间再试。
  • 全程在浏览器本地运行，数据不经过服务器，刷新页面即清空。

常见问题

这个 JSON 美化工具收费吗？

免费且隐私安全，美化完全在浏览器本地运行。

支持哪些缩进选项？

你可以选择 2 个空格、4 个空格或 Tab 缩进，让输出贴合你的项目风格。

能按字母排序键吗？

可以。勾选「按键排序 A–Z」后，美化器会把每个对象的键按字母顺序重新排列，更方便查看。

美化会改变我的数值吗？

不会。它只重新排版空白（并可选择键顺序），数据本身完全不变。

怎么用

  1. 把紧凑的 JSON 粘贴进输入框
  2. 选好缩进方式，需要的话勾选按键名排序
  3. 点美化按钮
  4. 下方立刻得到格式化好的 JSON，点复制按钮取走

适用场景

  • 调试接口时返回的 JSON 挤成一团，先美化再看
  • 提交配置文件前排版，方便同事评审
  • 对比两份 JSON 的结构差异
  • 把日志里的 JSON 片段整理成可读格式
