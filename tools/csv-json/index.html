CSV 与 JSON 互转工具

本工具用于在 CSV 表格数据与 JSON 对象数组之间进行双向转换。您只需在下方文本框中粘贴 CSV 文本或 JSON 文本，选择转换方向后点击「转换为 JSON」或「转换为 CSV」按钮，结果会立即显示在下方结果区。工具会自动识别 CSV 的表头行与分隔符（支持逗号、制表符、分号），所有数据均在浏览器本地处理，不会上传到任何服务器。

注意事项

  • CSV 转 JSON 时，默认将第一行作为表头（字段名），后续每行数据生成一个 JSON 对象。
  • CSV 字段若包含分隔符、换行符或双引号，需用双引号包裹，且内部双引号需用两个双引号转义。
  • JSON 转 CSV 时，仅支持对象数组（数组内元素为扁平对象），嵌套对象或数组会被序列化为 JSON 字符串。
  • 所有转换均在浏览器本地完成，数据不会离开您的设备，请放心粘贴敏感数据。
  • 若 CSV 各行列数不一致，将按表头列数截断或补空字符串处理。
  • 大文件（超过 5 万行）可能导致页面卡顿，建议分批处理。

怎么用

  1. 在顶部选择转换方向：CSV 转 JSON 或 JSON 转 CSV。
  2. 将数据粘贴到上方文本框中，或点击「示例 CSV」「示例 JSON」快速填充演示数据。
  3. 如需自定义 CSV 分隔符，可在下拉框中选择逗号、制表符、分号或竖线。
  4. 点击「转换为 JSON」或「转换为 CSV」按钮（按钮文字随模式变化），结果会显示在下方结果区。
  5. 点击「复制结果」可将转换后的文本复制到剪贴板，点击「重置」清空所有内容。

常见问题

CSV 文件里含有逗号怎么办

CSV 规范要求包含逗号、换行符或双引号的字段必须用双引号包裹，例如 "北京, 上海"。本工具支持这种标准转义格式。

JSON 转 CSV 时嵌套对象怎么处理

嵌套对象或数组会被自动序列化为 JSON 字符串写入对应单元格，您可以在 Excel 中查看完整结构，但无法直接展开为多列。

转换结果和预期不符怎么办

请检查输入数据格式：CSV 是否包含表头行、JSON 是否为对象数组。也可尝试切换分隔符选项，或使用示例数据对比验证。

数据会上传到服务器吗

不会。本工具为纯前端实现，所有解析和转换逻辑都在您的浏览器中运行，没有任何网络请求，数据完全本地处理。
