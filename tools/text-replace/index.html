批量文本替换工具

批量文本替换工具是一款在浏览器本地运行的多条查找替换处理工具。您可以在上方输入原始文本，在下方添加多条「查找→替换」规则，支持普通文本与正则表达式两种模式。设置好规则后，点击「执行替换」按钮，右侧结果区会实时预览每次替换的命中位置与替换结果。所有数据仅在本机处理，不会上传到任何服务器。替换完成后，可点击「复制结果」按钮一键复制到剪贴板，方便粘贴到其他文档中使用。

执行替换后，此处会显示结果与命中标记

注意事项

  • 所有替换操作均在浏览器本地完成，您的文本不会上传到任何服务器，可放心处理敏感内容。
  • 启用正则表达式时，查找内容按 JavaScript 正则语法解析；若正则写错，会提示错误且不执行替换。
  • 替换规则按从上到下的顺序依次执行，后一条规则作用于前一条规则的结果上，请注意规则顺序。
  • 「全局替换」选项关闭时，每条规则只替换每行中第一个匹配项；开启时替换所有匹配项。
  • 预览区会以黄色高亮标记「查找命中」位置，以绿色高亮标记「替换后」内容，便于核对。
  • 本工具兼容 Chrome、Edge、Firefox、Safari 等现代浏览器，建议使用最新版本以获得最佳体验。

怎么用

  1. 在上方「原始文本」输入框中粘贴或输入需要处理的文本内容。
  2. 在「替换规则」区域点击「添加规则」按钮，或直接点击快捷预设按钮快速添加常用规则；每条规则包含「查找内容」和「替换为」两个输入框。
  3. 根据需要勾选「启用正则表达式」「忽略大小写」「全局替换」等选项。
  4. 点击「执行替换」按钮，下方「替换结果预览」区域会显示处理后的文本，并用颜色标记每次替换的命中位置。
  5. 确认结果无误后，点击「复制结果」按钮即可将替换后的文本复制到剪贴板，粘贴到目标位置使用。

常见问题

替换规则可以添加多少条

理论上没有数量限制，但建议控制在 20 条以内以保证执行效率和可读性。规则过多时可通过「清空规则」按钮一键重置。

正则表达式写错了怎么办

点击「执行替换」时若正则语法错误，页面会弹出红色错误提示，并定位到出错的那条规则。修正后重新执行即可。

替换结果和预期不一样

请检查规则顺序是否合理，因为替换是逐条依次执行的。另外确认「全局替换」和「忽略大小写」选项是否符合需求。

复制结果后粘贴格式会变吗

不会。复制的是纯文本内容，换行符和空格会原样保留。粘贴到支持纯文本的编辑器中格式完全一致。
