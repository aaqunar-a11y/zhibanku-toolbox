正则表达式测试器 — 在线测试正则

「正则表达式测试器」帮你在线验证一段正则写得对不对。在页面上方第一栏填入正则表达式，第二栏粘贴要匹配的测试文本，需要忽略大小写或全局匹配时勾选对应标志，接着点「开始测试」按钮，下方就会列出每一处匹配的位置、匹配到的内容，以及各个捕获组分别取到了什么。表达式和文本都在浏览器本地运行，改一次点一次，调试查错非常直观，不用装任何软件。

输入正则、可选标志与测试文本，列出每个匹配的位置与捕获组。纯前端运行。

注意事项

  • 用的是浏览器自带的 JavaScript 正则引擎，Python、Java 里的写法不一定通用，比如命名分组 (?P<名字>) 这种语法不支持
  • 加上 g 标志才会列出全部匹配，不加通常只返回第一处，明明有多处却只显示一个时先检查标志
  • 点号、括号、星号在正则里另有含义，想匹配它们本身必须加反斜杠转义，否则会匹配到一堆意外内容
  • 空表达式或 a* 这类能匹配空串的写法会刷出海量结果，容易把页面卡住，建议先限定一个具体字符
  • 表达式和测试文本都只在本地计算，不发往服务器，但调试时别把身份证号、密码这类真实数据贴进来

常见问题

使用哪种正则引擎？

使用浏览器内置的 JavaScript（ECMAScript）正则引擎，语法与网页代码一致。

标志有什么作用？

常用标志：g（全局，匹配全部）、i（忽略大小写）、m（多行）、s（dotAll），行为与 JavaScript 完全一致。

会上传我的数据吗？

不会。匹配完全在浏览器本地进行。

怎么用

  1. 在表达式框输入正则，注意用反斜杠转义特殊符号。
  2. 选好标志位，比如全局匹配或忽略大小写。
  3. 把待测文本粘进下方测试区，点「测试」按钮。
  4. 结果区列出每个匹配的位置、原文与捕获组，并在原文里高亮标出。

适用场景

  • 校验手机号、邮箱等表单规则前先跑几组样例。
  • 从一大段日志里提取固定格式的条目。
  • 改完正则立刻验证，确认没把不该匹配的内容也抓进来。
