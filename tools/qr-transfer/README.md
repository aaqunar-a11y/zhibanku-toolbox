## 📖 简介

免费二维码传文件工具：手机电脑扫码互传文件，点对点直连不经过服务器，断网也能用。无需安装、无需注册、不限文件大小，单文件离线部署，开源免费。

两台设备扫描二维码直接连接，文件从一台设备直达另一台，不经过任何服务器、不上传云端。本工具完全本地运行，断开网络也能完成配对与传输（同一局域网内）。无需安装、无需注册，任意格式任意大小。

## 🚀 使用方式

### 在线使用

直接打开 <https://www.zhibanku.com/tools/qr-transfer.html>，无需安装。

### 离线使用（推荐）

1. 下载本目录的 [`index.html`](index.html)；
2. 双击用任意现代浏览器打开即可，无需联网、无需安装。

### 自行部署

把 `index.html` 放到任意静态服务器、GitHub / Gitee Pages 或内网共享目录即可。
