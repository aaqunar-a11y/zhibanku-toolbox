# 命名风格转换

camelCase / PascalCase / snake_case / kebab-case / CONSTANT_CASE 等 9 种风格互转。

- 在线使用：<https://www.zhibanku.com/tools/case-converter.html>
- 本目录源码：[`index.html`](index.html)（单文件，零依赖，双击即可在浏览器打开）

## 实现要点

支持驼峰切分、连续大写缩写（`HTTPServer`）与数字边界切分。

## 隐私

页面不发起任何网络请求、不写 Cookie、不使用 localStorage。所有计算在浏览器本地完成。
