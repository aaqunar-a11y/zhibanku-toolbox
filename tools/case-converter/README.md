## 📖 简介

知办库免费在线命名风格转换工具：一键在 camelCase、PascalCase、snake_case、kebab-case、CONSTANT_CASE 之间互转，支持中划线、空格与连续大写输入。纯前端运行，不上传数据。

把变量名、文件名、接口字段在常见命名约定之间互相转换。支持拆分 camelCase、snake_case、kebab-case、空格与连续大写缩写（如 HTTPServer）。纯前端运行。
