在线字数统计 — 实时统计字数、字符与阅读时长

「在线字数统计」会实时给出中文字数、字符数（含空格与不含空格两种口径）、句子数、段落数和预计阅读时长。把要统计的文字粘贴到页面上方的输入框，或者直接用键盘输入，下方的数字会跟着自动刷新；想重新核对一遍时，点「开始统计」按钮再算一次也行。所有结果都显示在输入框正下方的统计面板里，改一个字立刻更新，全程在浏览器本地运行，文字不会离开你的设备。

在下方输入或粘贴文字，统计结果随输入实时更新，全过程在你的浏览器本地完成，文字不会上传。

注意事项

  • 中文按字逐个计，英文按空格分词，标点符号单独计入字符数，但不单独算作一个中文字
  • 段落按空行划分，段落中间的换行不单独算一段，只按回车分段时段落数可能比预期少
  • 含空格与不含空格是两套口径，交稿前先确认对方要求哪一种，别把数字报错了
  • 文本只在浏览器里统计，不上传服务器；刷新或关掉页面结果就清空，记得先复制走
  • 几万字的大文本每次输入都会重算，可能短暂卡顿，粘贴完成后再统一修改更流畅

常见问题

这个字数统计工具收费吗？

完全免费。知办库字数统计无需注册、不限次数，长期使用不收费。

我输入的文字会被上传吗？

不会。所有统计都在你浏览器本地用 JavaScript 完成，文字不会发送到任何服务器，保护隐私。

中英文混排时字数怎么算？

每个汉字按 1 个字计算，英文单词按空格切分，所以中英文混排也能准确统计。

阅读时长是怎么估算的？

按每分钟约 300 字（中文）估算，不足 1 分钟显示「<1分钟」，向上取整。

怎么用

  1. 把文本粘进编辑区，或直接在里面输入。
  2. 顶部立刻显示中文字数与总字符数，可切换含不含空格。
  3. 下方分列句子数、段落数与预计阅读时长。
  4. 点「清空」重新来过，或点复制把统计结果带走。

适用场景

  • 写作文或论文时随时看还差多少字。
  • 核对会议纪要、周报的篇幅是否合适。
  • 做短视频口播稿，控制在规定时长对应的字数内。
