Markdown 转 HTML

Markdown 转 HTML 工具帮你把 Markdown 文本一键变成干净的 HTML 代码，支持标题、列表、代码块、链接、图片等常用写法，全程在浏览器本地完成，内容不会上传服务器。把写好的 Markdown 粘贴到页面上方的输入框里，或者直接把 .md 文件拖进输入区，然后点「开始转换」按钮，右侧结果区就会立刻显示生成的 HTML，整段选中即可复制去用。

由 Markdown 源码得到 HTML 输出。

注意事项

  • 支持标题、段落、有序与无序列表、引用、代码块、行内代码、链接、图片、表格、粗斜体等常用写法；脚注、任务列表这类扩展语法会按普通文本原样输出。
  • 转换全程在浏览器本地完成，粘贴的内容不会离开你的电脑，但刷新或关闭页面后输入框会被清空，重要文稿请自行留存一份。
  • 输出的正文字符已做转义，链接地址和图片地址按原样保留，嵌入第三方内容前请自行确认来源是否可信。
  • 代码块的语言标记以属性形式输出，粘到不带代码高亮样式的页面里不会自动上色，需要配合高亮脚本使用。
  • 几万字以上的长文档一次性转换会让页面短暂卡顿，建议分段粘贴处理。

常见问题

支持哪些语法？

标题、加粗、斜体、代码、列表、链接、引用、分隔线。

输出安全吗？

应用格式规则前先转义文本。

转换出来的代码能直接放进网页吗

可以，把结果整段粘到页面正文或模板里就能显示。标题、列表会自动套用你页面已有的样式，不需要额外加类名。

表格和任务列表支持吗

标准写法的表格支持，会输出 table 结构。任务列表这种扩展语法目前按普通列表处理，勾选框不会生成。

输入的内容会被保存下来吗

不会。转换在浏览器本地完成，内容不上传，刷新或关掉页面就没了，需要留底请自己复制保存。

能把 HTML 反向转回 Markdown 吗

本工具只做单向转换。需要反向处理时，可以先用 HTML 转纯文本工具提取正文，再手动补回 Markdown 标记。

怎么用

  1. 把 Markdown 原文粘贴到左侧输入框。
  2. 点「转换」按钮。
  3. 右侧显示对应的 HTML 代码，点复制按钮拿走即可。

适用场景

  • 把写好的说明文档一键转成网页，直接嵌进站点。
  • 博客编辑器只收 HTML 时，用它快速过一遍格式。
  • 检查自己的 Markdown 写法是否规范，看生成结果有没有偏差。
