TOML 与 JSON 互转工具

本工具用于在 TOML 与 JSON 两种数据格式之间进行双向转换。您只需在左侧输入框中粘贴原始内容，然后点击「TOML 转 JSON」或「JSON 转 TOML」按钮，转换结果会立即显示在下方结果区。整个过程完全在您的浏览器本地完成，数据不会上传到任何服务器。转换结果支持一键复制，方便您直接用于配置文件或开发调试。

注意事项

  • 本工具完全在浏览器本地运行，您的数据不会上传到任何服务器，请放心使用。
  • TOML 转 JSON 时，TOML 中的日期时间类型（如 1979-05-27T07:32:00Z）会转换为 ISO 8601 字符串。
  • JSON 转 TOML 时，JSON 对象键名必须符合 TOML 的裸键规则（仅允许字母、数字、下划线、连字符），否则会报错。
  • TOML 中的多行字符串（使用三个引号）在转换时会保留换行符，JSON 中会显示为 \n 转义。
  • 不支持 TOML 中的内联表（inline table）以外的复杂嵌套类型，如数组中的混合类型数组。
  • JSON 中的 null 值在 TOML 中没有对应类型，转换时会报错提示。

怎么用

  1. 在「输入内容」文本框中粘贴您要转换的 TOML 或 JSON 数据。
  2. 根据输入内容的格式，点击「TOML 转 JSON」或「JSON 转 TOML」按钮。
  3. 转换结果会显示在下方「转换结果」文本框中，并自动格式化缩进。
  4. 点击「复制结果」按钮可将转换后的内容复制到剪贴板。
  5. 如需重新开始，点击「重置」按钮清空所有输入和输出。

常见问题

转换失败提示语法错误怎么办

请检查输入内容是否符合 TOML 或 JSON 的语法规范。特别注意引号是否闭合、逗号是否遗漏、键名是否合法。

TOML 中的日期时间会变成什么

TOML 的日期时间类型（如 1979-05-27T07:32:00Z）在转换为 JSON 时会变成 ISO 8601 格式的字符串，例如 1979-05-27T07:32:00.000Z。

JSON 中的 null 值能转换吗

不能。TOML 格式没有 null 类型，遇到 JSON 中的 null 值会报错。建议先将 null 替换为其他值或移除该字段。

支持大文件转换吗

受浏览器性能限制，建议输入内容不超过 1MB。过大的文件可能导致页面卡顿或内存不足。
