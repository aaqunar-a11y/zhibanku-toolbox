QueryString 生成解析工具

本工具用于 URL 查询字符串（QueryString）与键值对之间的双向转换。您可以在上方输入框粘贴一段带查询参数的 URL 或纯查询字符串，也可以直接输入键值对（每行一个，格式为「键=值」）。点击「解析查询字符串」按钮，即可将 URL 中的参数拆解为清晰的键值对列表；点击「生成查询字符串」按钮，则可将键值对合并为规范的查询字符串。解析结果会显示在下方结果区，同时支持一键复制。所有操作均在浏览器本地完成，数据不会上传到任何服务器。

快捷预设：
提示：解析模式支持完整 URL（如 https://example.com/path?name=张三&age=25）或纯查询字符串（如 name=张三&age=25）。生成模式每行输入一个键值对，格式为「键=值」。

结果

注意事项

  • 解析时自动处理 URL 编码（如 %20 会解码为空格，%E4%B8%AD 会解码为「中」），生成时自动对特殊字符进行编码。
  • 生成模式要求每行一个键值对，格式为「键=值」。如果某行没有「=」号，该行将被忽略并给出提示。
  • 解析时若 URL 中包含多个同名参数（如 ?a=1&a=2），结果会保留所有值，每行显示一个。
  • 本工具完全在浏览器本地运行，不会将任何数据发送到服务器，请放心使用。
  • 生成结果默认按输入顺序排列，不会自动排序。如需排序，请手动调整输入顺序。
  • 解析时若输入内容不是合法 URL 或查询字符串，会提示错误，请检查输入格式。

怎么用

  1. 选择模式：点击「解析模式」或「生成模式」按钮切换功能。默认是解析模式。
  2. 输入内容：在输入框中粘贴 URL、查询字符串，或按「键=值」格式逐行输入键值对。
  3. 点击按钮：解析模式点击「解析查询字符串」，生成模式点击「生成查询字符串」。
  4. 查看结果：处理结果会显示在下方结果区，点击「复制结果」按钮可一键复制到剪贴板。
  5. 如需快速体验，可点击「快捷预设」中的按钮，自动填入示例数据。

常见问题

解析时遇到中文乱码怎么办

本工具会自动进行 URL 解码，中文会正常显示。如果仍有乱码，请确认输入内容是否为标准 URL 编码格式。

生成时键或值包含特殊字符如何处理

工具会自动对特殊字符（如空格、&、=、# 等）进行 URL 编码，生成规范的查询字符串，无需手动处理。

支持解析完整 URL 吗

支持。您可以粘贴完整的 URL（包含协议、域名、路径），工具会自动提取问号后面的查询部分进行解析。

结果可以复制到剪贴板吗

可以。点击结果区下方的「复制结果」按钮，即可将结果内容复制到系统剪贴板，方便粘贴到其他地方。
