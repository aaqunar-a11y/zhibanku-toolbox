JSON 对比工具 本地运行

本工具用于并排对比两份 JSON 数据的差异，自动高亮新增、删除与修改的字段路径。您只需在左侧两个输入框中分别粘贴或输入 JSON 内容，然后点击「开始对比」按钮，差异结果会以左右并排的方式展示，同时列出所有变更路径。整个过程完全在浏览器本地完成，数据不会上传到任何服务器，可放心处理敏感数据。

    注意事项
    
  
      
    
    • 输入内容必须是合法 JSON，否则会提示错误；支持对象、数组、字符串、数字、布尔值和 null。
      • 
    
    • 对比基于 JSON 解析后的结构，键值顺序不同不会视为差异，但数组顺序变化会显示为修改。
      • 
    
    • 所有处理均在浏览器本地完成，数据不会离开您的设备，请放心粘贴敏感内容。
      • 
    
    • 对于大型 JSON（超过 1MB），页面可能出现卡顿，建议先压缩或分段对比。
      • 
    
    • 差异高亮采用行级标记，同一行内多个差异会合并显示，路径列表提供精确位置。
      • 
    
    • 复制结果会生成纯文本格式的差异报告，包含路径和变更类型，方便分享或记录。
      • 
  
    

  
    怎么用
    
  
      
    
    1. 在左侧「原始 JSON」输入框中粘贴第一份 JSON 内容。
      2. 
    
    2. 在右侧「对比 JSON」输入框中粘贴第二份 JSON 内容。
      3. 
    
    3. 点击「开始对比」按钮，系统会自动解析并比较两份 JSON。
      4. 
    
    4. 对比结果会在下方区域展示：左右并排显示差异高亮，上方列出所有变更路径。
      5. 
    
    5. 如需复制差异报告，点击「复制结果」按钮即可。

    常见问题
    
  
    
    JSON 格式错误怎么办
    
    页面会提示具体错误位置，请检查括号、引号、逗号是否完整。可使用本页的 JSON 校验工具先验证格式。
    
  
    
  
    
    数组顺序不同算差异吗
    
    算。数组按索引逐项对比，顺序变化会导致对应位置显示为修改。若需忽略顺序，可先排序再对比。
    
  
    
  
    
    对比结果如何解读
    
    绿色背景表示新增内容，红色删除线表示移除内容，黄色背景表示修改内容。路径列表给出精确的字段位置。
    
  
    
  
    
    数据会传到服务器吗
    
    不会。所有解析和对比逻辑都在浏览器本地执行，无任何网络请求，数据完全离线处理。
