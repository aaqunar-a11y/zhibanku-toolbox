XML 格式化工具

本工具用于格式化、压缩和校验 XML 内容。您可以在下方输入框中粘贴或直接输入 XML 代码，点击「格式化」按钮即可得到缩进整齐、结构清晰的 XML；点击「压缩」按钮可去除多余空白；点击「校验」按钮可检查标签闭合与语法错误。格式化结果会显示在下方结果区，并支持一键复制。所有处理均在您的浏览器本地完成，不会上传任何数据。

注意事项

  • 本工具仅支持标准 XML 语法，不支持 DTD 外部实体解析，遇到未知实体可能报错。
  • 所有处理均在浏览器本地完成，您的 XML 内容不会上传到任何服务器，可放心处理敏感数据。
  • 格式化时默认保留 XML 声明（<?xml?>），压缩时会移除多余空白但保留声明。
  • 如果 XML 中包含中文注释或 CDATA 内容，请确保文件编码为 UTF-8，否则可能出现乱码。
  • 校验功能会检查标签闭合、属性引号、命名空间等常见语法问题，但不保证完全符合 XML 1.0 规范。
  • 超大 XML（超过 5MB）可能导致浏览器卡顿，建议分段处理。

怎么用

  1. 在「输入 XML」区域的文本框中粘贴或输入您的 XML 内容。
  2. 根据需要选择缩进宽度（默认 4 空格），或点击上方「快捷用法」中的示例按钮快速填充测试内容。
  3. 点击「格式化」按钮，工具会自动整理缩进和换行；点击「压缩」可去除多余空白；点击「校验」可检查语法错误。
  4. 处理完成后，结果会显示在下方「结果」区域的文本框中，点击「复制结果」按钮即可复制到剪贴板。
  5. 如需重新开始，点击「重置」按钮清空所有输入和输出。

常见问题

格式化后 XML 结构乱了怎么办

请检查原始 XML 是否包含未闭合的标签或非法字符。可先点击「校验」按钮查看具体错误位置，修正后再格式化。

支持处理带命名空间的 XML 吗

支持。工具会保留 xmlns 属性，并按标准方式处理带前缀的标签。但不会验证命名空间 URI 的有效性。

压缩模式会删除哪些内容

压缩会移除标签之间的空白字符、多余换行和缩进，但会保留 CDATA 内部内容和注释。XML 声明也会保留。

结果区的内容可以编辑吗

结果区为只读模式，防止误操作。如需修改格式化结果，请复制到输入区调整后再重新格式化。
