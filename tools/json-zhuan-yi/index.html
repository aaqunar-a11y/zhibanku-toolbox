JSON 转义与反转义 — 让字符串适配 JSON

知办库 JSON 转义与反转义工具解决一个很常见的麻烦：文字里带引号、反斜杠或换行时，直接塞进 JSON 就会报错。把普通文字粘到上方输入框，点「转义」按钮，下方输出框会给出带反斜杠的字符串内容，可以直接放进 JSON 的值里；反过来点「反转义」，就能把转过的内容还原成原文，结果同样显示在下方，随时可复制使用。

选择「转义」或「反转义」，粘贴文字即可即时转换。全过程本地完成、不上传。

选择模式后开始转换。

注意事项

  • 输出的是字符串内部内容，不含首尾双引号，嵌入 JSON 时需要自己补上一对引号
  • 支持换行、制表符、双引号、反斜杠等常见字符，控制字符按 JSON 规范处理
  • 反转义对没转义过的普通文本同样安全，不会改变原内容
  • 全部在浏览器本地执行，输入的文字不会上传到服务器
  • 结果是单行文本，粘回编辑器时注意别被自动换行截断
  • 中文与 emoji 转义后保持原样，不会变成问号或乱码

常见问题

这个 JSON 转义工具收费吗？

免费且隐私安全，转义与反转义都在浏览器本地完成。

转义字符串是做什么？

它把普通文字变成 JSON 安全的字符串字面量：引号、反斜杠以及换行等控制字符都会被转义（例如换行变为 \n），从而能安全地嵌入 JSON 值中。

什么时候需要转义 JSON 字符串？

当你手写 JSON、或把用户输入的文字塞进某个 JSON 值时——转义可避免引号与特殊字符破坏语法。

反转义可逆吗？

可逆。反转义会把 JSON 字符串字面量还原为原始文字，恢复真实的换行、Tab 与引号。

怎么用

  1. 把要处理的文字粘贴到输入框。
  2. 需要转义就点「转义」，需要还原就点「反转义」。
  3. 结果出现在下方输出框，直接复制走，粘进 JSON 里就能用。

适用场景

  • 接口文档里要写一段带换行的提示语，转义后再放进参数。
  • 拿到别人给的一串带反斜杠的字符串，反转义还原成能读懂的原文。
  • 批量处理配置里的路径和模板文本，避免手写转义符写漏。
