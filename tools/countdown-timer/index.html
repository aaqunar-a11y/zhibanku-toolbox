倒计时器

倒计时器帮你对任意一个日期时间做倒数，比如活动开抢、会议开始、发版截止。打开页面后，在目标时间输入框里选好年月日时分秒，也可以顺手填一句提醒文字，再点「开始倒计时」按钮，页面就会实时显示剩余的天、时、分、秒。倒计时结束时会弹出提示并响铃。所有计算都在你的浏览器里完成，目标时间不会上传到服务器，数据只留在本地。结果就在下方的计时面板里看到，随时可以暂停或重新开始。

追踪距离事件的剩余时间。

快捷预设：
请填写目标时间，然后点「开始」。

注意事项

  • 倒计时依赖系统时钟，如果手动改了电脑或手机时间，剩余时长会跟着变
  • 把页面切到后台或最小化时，浏览器可能限制刷新频率，提示音或归零提醒会晚几秒出现
  • 关掉标签页或刷新页面后倒计时不会自动恢复，需要重新选目标时间再点开始
  • 数据只保存在当前浏览器会话里，换设备、换浏览器打开都不会同步
  • 提示音需要页面已获得播放权限，手机静音或从未点击过页面时可能听不到声音
  • 目标时间精确到秒，跨越夏令时或时区调整的地区，实际到点时刻以你设备的本地时间为准

常见问题

时区？

目标使用你设备的本地时间。

可离线吗？

可以，加载后本地计时，无网络。

倒计时归零之后会自动停下来吗

会。剩余时间减到零后刷新停止，页面弹出醒目的结束提示并播放提示音，点重新开始就能再跑一轮。

可以同时跑几个倒计时吗

当前页面一次只维护一个目标时间。需要多个同时倒数的话，可以开几个标签页分别设定，互不影响。

手机浏览器上能正常用吗

可以，页面按手机屏幕做了适配。锁屏或切到别的应用时计时可能暂停，回到页面会按系统时间自动补算剩余时长。

把目标时间设成过去会怎样

选了早于当前的时刻会直接提示无效，不会开始计时，需要重新挑一个将来的时间点再点开始倒计时。

怎么用

  1. 在日期和时间框里选好目标时刻，也可以直接输入。
  2. 点开始按钮，倒计时立刻跑起来。
  3. 页面上会显示剩余的天数、小时、分钟和秒。
  4. 需要暂停就点暂停按钮，要改目标就点重设按钮重新填。

适用场景

  • 盯产品上线时间，随时看到还剩多久。
  • 考试或比赛前设定节点，避免错过开始时间。
  • 记录某个纪念日还有多少天，打开页面就能看。
