YAML 与 JSON 互转工具

这是一个在浏览器本地完成 YAML 与 JSON 双向转换的实用工具。您只需在左侧输入框中粘贴 YAML 或 JSON 内容，点击「转为 JSON」或「转为 YAML」按钮，右侧结果区就会立即显示转换后的格式化文本。工具内置语法校验，出错时会明确提示问题位置。所有数据均在您的浏览器内处理，不会上传到任何服务器，可放心处理敏感配置内容。

快捷示例：
YAML 输入 YAML
JSON 输出 JSON

注意事项

  • 本工具完全在浏览器本地运行，所有数据不会离开您的设备，请放心处理敏感配置。
  • YAML 解析遵循 YAML 1.2 核心规范，不支持自定义标签、锚点引用等高级特性。
  • JSON 转 YAML 时，字符串中的特殊字符（如冒号、井号）会自动加引号处理，避免歧义。
  • YAML 中的日期时间字符串会被解析为字符串，不会自动转为日期对象。
  • 输入内容过大（超过 1MB）时可能影响转换速度，建议分段处理。
  • 缩进设置仅影响输出格式，不影响数据内容本身。

怎么用

  1. 在左侧输入框中粘贴或输入您的 YAML 或 JSON 内容，也可以点击上方快捷示例按钮快速填充。
  2. 根据输入内容选择转换方向：默认是「YAML 转 JSON」，如需反向转换请点击「JSON 转 YAML」按钮。
  3. 点击「转为 JSON」或「转为 YAML」按钮（按钮文字会随方向切换），转换结果会显示在右侧输出区。
  4. 如需调整输出缩进，可在下方下拉框选择 2 空格、4 空格或 Tab 制表符，然后重新点击转换按钮。
  5. 点击「复制结果」可将输出内容复制到剪贴板，点击「重置」可清空所有输入输出。

常见问题

转换失败时提示语法错误怎么办

请检查输入内容是否符合对应格式规范。YAML 注意缩进一致性，JSON 注意引号和逗号。错误提示会指出具体行号和原因，按提示修正即可。

YAML 中的注释会被保留吗

不会。注释是 YAML 的辅助信息，转换时会被忽略。如果需要在 JSON 中保留说明，建议使用描述性字段名。

支持 YAML 锚点和别名吗

不支持。本工具使用简化版 YAML 解析器，锚点、别名、合并键等高级特性会被当作普通文本处理，建议先展开再转换。

转换结果和预期不一致怎么办

检查输入中的特殊字符，如字符串包含冒号或井号时 YAML 需要加引号。JSON 转 YAML 时工具会自动处理，但 YAML 转 JSON 需要您确保输入格式正确。
