离线中英翻译工具

本工具内置 8000 个核心词，开箱即用；需要更高覆盖率时，点一次「加载完整词典」即可把 12.4 万词的完整词典下载并永久保存在你的浏览器里，之后断网也能用。整句译文 + 逐词对照一并给出，输入的文字全程留在本地，不联网、不上传。

词典状态：内置核心词 8000 个（可离线使用）
词典规模：内置 8000 词；加载完整词典后 124,000+ 词。

怎么用

  1. 在上方输入框粘贴或输入一段中文或英文文本（默认自动识别语言方向，也可以点「方向」按钮强制指定）。
  2. 点击蓝色的「立即翻译」按钮，结果区会立刻显示译文，不需要等待网络请求。
  3. 想让生僻词也能翻译，先点一次「加载完整词典」，下载完成后再翻译，覆盖率会大幅提升。
  4. 译文下方的词卡是逐词对照，橙色词卡表示词典未收录、保留原文。
  5. 点击「复制结果」把译文复制到剪贴板，点击「清空重填」重新开始。

注意事项

  • 本工具是词典对照式翻译，不是人工智能翻译：长难句只做逐词对照与短语替换，用于「看懂大意」，不适合直接产出正式译文。
  • 内置核心词 8000 个，覆盖日常高频词；完整词典 124,000+ 词（含柯林斯、牛津、语料库高频词与技术词汇），首次点击「加载完整词典」后永久保存在本机浏览器缓存中。
  • 完整词典文件由本站服务器提供，下载后即缓存；此后即使断网、拔网线，再次打开本页也仍然可用。
  • 英文动词时态与名词复数（ing、ed、s、ies 等）会自动回退到词根查找，但译文不区分时态，仅供理解参考。
  • 工具完全在浏览器本地运行，输入的任何文字都不会被发送或保存；把本页面另存为 html 文件即可长期随身携带。
  • 手机端同样可用，页面无需登录、无广告、无弹窗。

常见问题

为什么有些词显示「未收录」？

内置核心词有 8000 个，遇到专业术语、长尾词会保留原文并标橙色。点击上方「加载完整词典」按钮，把 12.4 万词的完整词典下载到本机后，绝大多数常见英文单词都能查到。

加载完整词典要联网吗？之后还能离线用吗？

下载词典的那一次需要联网（约 2.4MB，走 gzip 压缩）。下载完成后会写入浏览器本地存储，此后再次打开本页不再请求网络，断网也能用完整词典。

词典数据会被更新吗？

词典文件带版本号，工具只在检测到新版本时才重新下载。你也可以随时点「重新下载词典」强制更新。

输入的文字会被上传到服务器吗？

不会。翻译在你的浏览器内存中完成；联网请求只有一个——下载词典文件本身。本页没有任何表单提交、接口请求或统计埋点参与翻译流程。

怎么把这个工具长期留在电脑上？

浏览器菜单选择「网页另存为」保存本 html 文件，或下载下方压缩包解压后双击打开，之后随时离线使用，双击即可，不需要安装。
