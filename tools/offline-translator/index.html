离线中英翻译工具

本工具把一本简明中英词典直接内置在网页文件里：在输入框输入中文或英文文字，点击「立即翻译」按钮，下方的结果区会立刻显示整句译文和逐词对照。全程在你的浏览器内完成，不联网、不上传任何文字，断网电脑、内网办公机上也能照常使用。

词典规模：约 400 个常用词与短句。

怎么用

  1. 在上方输入框粘贴或输入一段中文或英文文本（默认自动识别语言方向，也可以点「方向」按钮强制指定）。
  2. 点击蓝色的「立即翻译」按钮，结果区会立刻显示译文，不需要等待网络请求。
  3. 译文下方的词卡是逐词对照，橙色词卡表示词典暂未收录、保留原文。
  4. 点击「复制结果」把译文复制到剪贴板，点击「清空重填」重新开始。

注意事项

  • 本工具是离线简明词典翻译，覆盖日常高频词与短句（问候、问路、购物、时间、数字等），不是机器深度学习翻译，长难句只能给出逐词对照。
  • 词典暂未收录专业术语、人名地名和网络新词，这类词会保留原文并标橙色，方便你另行查证。
  • 英文动词的时态变化（ing、ed、s 等）会自动回退到词根查找，但译文不区分时态，仅供理解参考。
  • 中文译英文按词逐一对应，语序不重排，复杂句子建议结合逐词对照人工整理。
  • 工具完全在浏览器本地运行，输入的任何文字都不会被发送或保存；保存本页面为 html 文件即可长期离线使用。
  • 手机端同样可用，页面无需登录、无广告、无弹窗。

常见问题

真的完全不需要联网吗？

完全不需要。词典数据直接写在本网页文件内部，打开页面后翻译过程不发起任何网络请求。你可以在断网环境（飞行模式、内网机）打开本页验证：照样能翻译。

翻译准确吗？能替代正规翻译软件吗？

日常短句（问候、问路、购物、致谢）可达意；长句、专业内容只能逐词对照，属于「看懂大意」级别。需要高质量全文翻译时请使用专业翻译服务，本工具的定位是断网可用与隐私安全。

输入的文字会被上传到服务器吗？

不会。整个翻译在你打开网页后于浏览器内存中完成，本页没有任何表单提交、接口请求或统计埋点参与翻译流程。

怎么把这个工具长期留在电脑上？

浏览器菜单选择「网页另存为」保存本 html 文件，或下载下方压缩包解压后双击打开，之后随时离线使用，双击即可，不需要安装。
