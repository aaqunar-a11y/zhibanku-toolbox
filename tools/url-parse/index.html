URL 解析工具

本工具用于将一段完整的网址（URL）拆解成协议、主机名、端口、路径、查询参数等组成部分，并逐项清晰展示。您只需在下方输入框中粘贴或输入网址，然后点击「解析 URL」按钮，结果就会在下方区域按条目列出，查询参数还会以表格形式呈现。整个过程完全在您的浏览器本地运行，不会把数据发送到任何服务器，请放心使用。

注意事项

  • 本工具仅支持标准格式的 URL 解析，若输入内容不是合法网址（如缺少协议头），将提示错误，请补全协议后再试。
  • 查询参数中若包含中文或特殊字符，工具会以原始编码形式展示，不会自动解码，如需解码请配合 URL 编解码工具使用。
  • 所有解析操作均在浏览器本地完成，您的网址内容不会上传到任何服务器，可放心粘贴敏感链接。
  • 对于没有明确端口号的网址，工具会显示「默认端口」并标注常见协议的默认值（如 HTTP 为 80，HTTPS 为 443）。
  • 哈希（锚点）部分不会被发送到服务器，但本工具会将其单独列出，方便您了解完整结构。
  • 若网址包含用户名密码（如 ftp://user:pass@host），工具会一并展示，请注意不要在公共场合粘贴含敏感信息的链接。

怎么用

  1. 在「输入网址」文本框中粘贴或输入您需要解析的完整网址，也可以点击上方任意一个快捷预设按钮快速填入示例。
  2. 点击蓝色「解析 URL」按钮，工具会立即对网址进行拆解。
  3. 解析结果会显示在下方区域，包含协议、主机、端口、路径、查询参数、哈希等条目，其中查询参数会以表格形式列出键值对。
  4. 如需复制解析结果，点击「复制结果」按钮即可将全部内容复制到剪贴板。
  5. 点击「重置」按钮可清空输入框和结果区域，重新开始解析。

常见问题

为什么我输入网址后提示解析失败

最常见原因是网址缺少协议头（如 http:// 或 https://）。请补全协议后再试，例如将 www.example.com 改为 https://www.example.com。

查询参数里的中文显示为乱码怎么办

这是 URL 编码的正常现象。本工具展示的是原始编码值，如需查看解码后的中文，请复制参数值到 URL 编解码工具中进行解码。

端口号没有显示出来是什么情况

当网址没有显式写端口时，工具会显示「默认端口」并标注该协议的标准端口号。例如 HTTPS 默认 443，HTTP 默认 80。

解析结果会保存在服务器上吗

不会。本工具是纯前端实现，所有解析逻辑都在您的浏览器中运行，没有任何数据上传，关闭页面即完全清除。
