JSON 压缩 — 把 JSON 缩到最小

知办库 JSON 压缩工具能一键把 JSON 里的多余空格、换行和缩进全部去掉，让文件缩到最小，并即时显示节省了多少字节。把接口返回或配置文件里的 JSON 粘贴到上方输入框，或者直接把 .json 文件拖进来，再点「开始压缩」按钮，压缩结果会显示在下方输出框里，同时标注压缩前后的体积对比，方便你直接复制使用。

注意事项

  • 压缩只删除空格、换行与缩进，键名顺序、数字精度和字符串内容都原样保留
  • 压缩后是不带换行的一整行文本，在部分编辑器里需要手动换行才好读
  • 文件超过几兆时，粘贴和压缩过程中浏览器可能短暂卡顿，建议分段处理
  • 整个过程在浏览器本地完成，输入的 JSON 不会上传到任何服务器
  • 原文若本身不合法会直接报错，建议先用校验工具确认再压缩
  • 浮点数按原样输出，不会四舍五入或改写成科学计数法

常见问题

这个 JSON 压缩工具收费吗？

免费且隐私安全，所有压缩都在浏览器本地完成。

压缩具体做什么？

它会移除所有多余的空格、换行与缩进，把 JSON 变成紧凑的一行，非常适合接口传输、存储和有体积限制的字段。

压缩会改变我的数据吗？

不会。压缩只去掉空白，数据和结构与原始输入完全一致。

能节省多少体积？

取决于原始空白的多少。每次压缩后，工具都会显示原始字节、压缩字节、节省字节与降幅百分比。

怎么用

  1. 把带缩进和换行的 JSON 粘贴进输入框
  2. 点压缩按钮
  3. 下方显示压缩后的结果，以及节省的字节数和百分比
  4. 点复制按钮，把最短版本拿走

适用场景

  • 接口返回体太大，压缩后塞进缓存
  • 把配置写成单行，方便存进环境变量
  • 前端打包时内嵌一份 JSON 数据，减少体积
  • 对比压缩前后大小，评估优化空间
