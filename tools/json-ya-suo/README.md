## ❓ 常见问题

<details>
<summary>这个 JSON 压缩工具收费吗？</summary>

免费且隐私安全，所有压缩都在浏览器本地完成。
</details>
<details>
<summary>压缩具体做什么？</summary>

它会移除所有多余的空格、换行与缩进，把 JSON 变成紧凑的一行，非常适合接口传输、存储和有体积限制的字段。
</details>
<details>
<summary>压缩会改变我的数据吗？</summary>

不会。压缩只去掉空白，数据和结构与原始输入完全一致。
</details>
<details>
<summary>能节省多少体积？</summary>

取决于原始空白的多少。每次压缩后，工具都会显示原始字节、压缩字节、节省字节与降幅百分比。
</details>
