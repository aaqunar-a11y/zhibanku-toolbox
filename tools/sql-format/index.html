SQL 格式化工具

本工具用于美化 SQL 语句，将杂乱的 SQL 整理成缩进清晰、关键字大写的规范格式，同时支持压缩成单行紧凑形式。您只需在下方输入框中粘贴原始 SQL，选择需要的方言类型和格式选项，点击「格式化 SQL」按钮，结果会立即显示在下方输出区域。支持 MySQL、SQL Server、Oracle 等常见数据库方言，所有处理均在浏览器本地完成，不会上传任何数据。

注意事项

  • 所有处理均在浏览器本地完成，您的 SQL 语句不会上传到任何服务器，可放心处理敏感数据。
  • 格式化基于词法分析，对复杂嵌套子查询、CTE 表达式、存储过程等高级语法可能无法完美还原缩进层级。
  • 字符串内的内容不会被格式化，保持原样输出，避免破坏字符串字面量的内容。
  • 不同数据库方言的专有语法（如 MySQL 的 LIMIT、Oracle 的 CONNECT BY）在格式化时可能无法完全识别。
  • 压缩成单行时，注释会被保留，但多余的空格和换行会被移除，请确认压缩后的语句在目标数据库可正常执行。
  • 如果输入包含语法错误或括号不匹配，工具会给出错误提示，但不会自动修复 SQL 逻辑问题。

怎么用

  1. 在「输入 SQL 语句」文本框中粘贴或输入需要格式化的原始 SQL 代码。
  2. 根据需要选择方言类型（MySQL、SQL Server 等）、是否关键字大写、缩进宽度等选项。
  3. 点击「格式化 SQL」按钮，工具会立即处理并显示格式化结果；如需压缩成单行，点击「压缩成单行」按钮。
  4. 格式化结果会显示在下方输出区域，同时展示字符数、行数、关键字数等统计信息。
  5. 点击「复制结果」按钮可将格式化后的 SQL 复制到剪贴板，方便粘贴到其他编辑器或数据库工具中。

常见问题

格式化后 SQL 能否直接执行

格式化只调整空格、换行和关键字大小写，不改变 SQL 逻辑结构，理论上可以直接执行。但建议先检查缩进层级是否清晰，确认无语法错误后再执行。

为什么我的存储过程格式化效果不好

存储过程包含 BEGIN...END、DECLARE、游标等复杂结构，词法分析器难以完美处理所有嵌套层级。建议手动检查关键部分的缩进，或使用数据库自带的格式化工具。

支持哪些 SQL 方言

内置支持 MySQL、SQL Server、Oracle、PostgreSQL、SQLite 五种常见方言，可识别各自的关键字和专有语法，但高级特性可能无法完全识别。

数据会被上传到服务器吗

不会。本工具完全在浏览器本地运行，所有处理逻辑都在 JavaScript 中完成，不发起任何网络请求，您的数据不会离开您的设备。
