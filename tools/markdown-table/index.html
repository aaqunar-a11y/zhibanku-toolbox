Markdown 表格转换器

本工具用于把 CSV、制表符分隔或管道符分隔的文本数据，一键转换为规范的 Markdown 表格。您只需在下方输入框粘贴原始数据，选择对应的分隔方式，点击「转换为表格」按钮，转换结果会立即显示在结果区。您还可以点击「复制结果」按钮将表格复制到剪贴板，方便粘贴到文档、博客或代码仓库中。整个过程完全在浏览器本地完成，数据不会上传到任何服务器。

注意事项

  • 自动识别分隔方式时，工具会优先检测制表符，其次是管道符，最后是逗号。如果数据中包含多种分隔符，建议手动选择。
  • CSV 数据如果包含引号包裹的字段（内含逗号），请选择「逗号（CSV）」模式，工具会正确解析引号内的逗号。
  • 所有数据仅在您的浏览器本地处理，不会上传到任何服务器，关闭页面后数据即消失。
  • 如果某行字段数量与其他行不一致，工具会以第一行的字段数为准，多余字段会被忽略，缺失字段会留空。
  • 转换结果中的 Markdown 表格使用标准语法，兼容 GitHub、Typora、语雀等主流 Markdown 渲染器。
  • 复制结果功能依赖浏览器的剪贴板权限，如果复制失败，请手动选中结果文本后按 Ctrl+C 复制。

怎么用

  1. 在输入框中粘贴您的数据，可以是 CSV（逗号分隔）、TSV（制表符分隔）或管道符分隔的文本。
  2. 选择分隔方式（推荐「自动识别」），如需自定义对齐方式，可在下拉框中选择。
  3. 点击「转换为表格」按钮，右侧结果区会立即生成 Markdown 格式的表格。
  4. 点击「复制结果」按钮，将表格复制到剪贴板，然后粘贴到您需要的地方。
  5. 如需重新开始，点击「重置」按钮清空所有内容。

常见问题

支持哪些输入格式

支持逗号分隔的 CSV、制表符分隔的 TSV 以及管道符分隔的文本。第一行会被识别为表头，后续行作为表格数据。

数据包含逗号怎么办

如果字段内容本身包含逗号，请用英文双引号将该字段包裹起来，并选择「逗号（CSV）」模式，工具会正确解析。

转换结果能直接用在 GitHub 吗

可以。工具生成的是标准 Markdown 表格语法，GitHub、GitLab、语雀、飞书文档等主流平台都支持直接渲染。

数据会上传到服务器吗

不会。所有转换操作都在您的浏览器本地完成，数据不会离开您的设备，请放心使用。
