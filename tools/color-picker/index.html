取色器

这是一款纯本地运行的取色与色值互转工具，您可以在下方色块中直接点选颜色，或在输入框中手动输入 HEX、RGB、HSL 任意一种格式的色值，然后点击「转换色值」按钮，即可在结果区看到三种格式的完整色值。每个结果旁都有「复制」按钮，方便您一键复制到剪贴板。工具还提供了 5 个快捷预设按钮，覆盖常用颜色，点一下即可快速取色。所有计算均在您的浏览器内完成，不会上传任何数据。

注意事项

  • 本工具完全在浏览器本地运行，您输入的颜色数据不会上传到任何服务器，可放心使用。
  • HEX 格式支持 3 位缩写（如 #1A5）和 6 位完整格式（如 #1A5FE0），也支持带透明度的 8 位格式（如 #1A5FE080）。
  • RGB 格式支持 0-255 的整数，也支持 0%-100% 的百分比写法（如 rgb(10%, 37%, 88%)）。
  • HSL 格式中 H 为 0-360 的角度值，S 和 L 为 0%-100% 的百分比，输入时请确保格式正确。
  • 如果输入格式有误，点击「转换色值」按钮后结果区会显示「格式错误」提示，请检查后重试。
  • 复制功能依赖浏览器剪贴板 API，部分旧版浏览器可能不支持，建议使用最新版 Chrome、Edge 或 Firefox。

怎么用

  1. 在「取色」处点击色块，直接弹出系统取色器选择任意颜色；或点击上方 5 个快捷预设按钮快速选用常用色。
  2. 您也可以在 HEX、RGB、HSL 三个输入框中手动输入任意一种格式的色值。
  3. 点击「转换色值」按钮，工具会自动将当前颜色转换为三种格式，并显示在下方结果区。
  4. 结果区每个色值右侧都有「复制」按钮，点击即可将该色值复制到剪贴板。
  5. 如需重新开始，点击「重置」按钮即可恢复默认颜色。

常见问题

为什么我输入的 RGB 颜色转换后结果不对

请检查 RGB 格式是否为 rgb(0-255, 0-255, 0-255) 或 rgb(0%-100%, 0%-100%, 0%-100%)，数值之间用英文逗号分隔，不要带多余空格。

支持带透明度的颜色吗

支持。HEX 格式可输入 8 位（如 #1A5FE080），RGB 格式可输入 rgba(26, 95, 224, 0.5)，HSL 格式可输入 hsla(219, 82%, 49%, 0.5)。

复制按钮没有反应怎么办

请确认浏览器是否为最新版本，并检查是否开启了剪贴板权限。部分浏览器在非安全上下文（如 http 协议）下会限制剪贴板功能。

颜色预览区域显示的颜色和实际有色差

不同显示器的色彩表现存在差异，这是硬件特性导致的正常现象。建议在专业显示器上校准色彩后使用。
