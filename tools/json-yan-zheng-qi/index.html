JSON 校验 — 检查 JSON 合法性并定位错误

知办库 JSON 校验工具用来检查一段 JSON 到底合不合法。把内容粘贴到上方输入框，或者直接拖入 .json 文件，然后点「开始校验」按钮，几秒内就会给出结论：出错时标出具体的行号和列号，方便你回去改；通过时还会给出结构摘要，包括顶层键、值类型和嵌套深度。校验结果与结构概览都显示在下方结果区，全程在浏览器里跑，不用登录也不用装软件。

注意事项

  • 按标准 JSON 规则判定，单引号、注释、尾部多余逗号都会被判为错误
  • 行号从 1 开始计数，列号按字符位置统计，粘贴时注意开头的不可见空格
  • 解析在浏览器本地完成，内容不会离开当前设备
  • 几兆以上的大文件解析时页面可能短暂无响应，建议分段校验
  • 校验只读不改，不会自动修正、补引号或重排你的内容
  • 结构摘要只统计键与深度，不回显完整数据，避免长内容刷屏

常见问题

这个 JSON 校验工具收费吗？

完全免费，无需注册，你的 JSON 只在浏览器本地处理，不会上传。

会指出错误位置吗？

会。当 JSON 不合法时，它会给出错误提示，并附带大致的出错行与列，方便你快速定位修复。

能校验很大的 JSON 吗？

可以。校验完全在浏览器本地运行，因此即便是较大的 JSON 也能处理，且不会上传到任何服务器。

它会改动我的 JSON 吗？

不会。校验器只检查合法性并展示结构摘要（键、值、数组、深度），不会重写或改变你的原始输入。

怎么用

  1. 把要检查的 JSON 文本粘贴到上方输入框里。
  2. 点「开始校验」按钮。
  3. 下方立刻给出结果：内容合法就显示键、值类型和嵌套深度的结构摘要；不合法就标出具体行号和列号，照着提示回去改就行。

适用场景

  • 调接口时拿到一大段返回数据，粘进来确认格式没坏。
  • 手改配置文件后，保存前先校验一遍，避免程序启动直接报错。
  • 同事发来的 JSON 看着正常却用不了，快速定位到底哪一列多了或少了符号。
